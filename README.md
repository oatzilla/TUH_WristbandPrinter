# TUH Wristband Printer (ระบบพิมพ์สายรัดข้อมือผู้ป่วย)
**โรงพยาบาลธรรมศาสตร์เฉลิมพระเกียรติ (Thammasat University Hospital)**

ระบบพิมพ์สายรัดข้อมือผู้ป่วยใน (IPD) เชื่อมต่อระบบโรงพยาบาล ePHIS พัฒนาด้วย C# Windows Forms (.NET Framework 4.0 x86) ออกแบบเพื่อความรวดเร็ว แม่นยำ และปลอดภัยสูงสุดสำหรับงานพยาบาลและเวชระเบียน

---

### 1. ฟังก์ชันและคุณสมบัติหลัก

#### 1.1 ช่องระบุหมายเลข HN / AN เด่นชัด (Prominent Search Bar)
* **กล่องข้อความขนาดใหญ่พิเศษ:** ตัวอักษรขนาด 15pt ตัวหนา คมชัด มองเห็นได้ง่ายแม้จากระยะห่าง
* **ระบบตรวจจับโฟกัส:** เปลี่ยนสีพื้นหลังเป็นสีฟ้าอ่อนทันทีเมื่อพร้อมรับการพิมพ์หรือยิงบาร์โค้ด
* **รองรับเครื่องอ่านบาร์โค้ด (Barcode Scanner):** สแกน HN หรือ AN แล้วกด Enter เพิ่มเข้าคิวได้ทันที
* **ปุ่มล้างข้อมูลด่วน (Esc):** ปุ่มสีแดง `✕ ล้างข้อมูล [Esc]` ล้างข้อมูลและนำเคอร์เซอร์กลับไปพร้อมสแกนรายใหม่ทันที

#### 1.2 ระบบจัดเก็บประวัติการพิมพ์ย้อนหลัง (Persistent Print History & Reprint)
* **บันทึกประวัติอัตโนมัติ:** จัดเก็บข้อมูลการพิมพ์ย้อนหลังทุกรายการลงฐานข้อมูลไฟล์ในเครื่อง (เก็บบันทึกได้ถึง 2,000 รายการ)
* **หน้าต่างค้นหาประวัติย้อนหลัง (ปุ่มลัด F4):**
  * ค้นหาได้รวดเร็วตาม HN, AN, ชื่อ-สกุล ผู้ป่วย หรือหอผู้ป่วย
  * กรองตามช่วงเวลา: วันนี้, ย้อนหลัง 3 วัน, ย้อนหลัง 7 วัน, หรือย้อนหลัง 30 วัน
  * **🖨️ พิมพ์ซ้ำทันที (Reprint):** กดพิมพ์สายรัดข้อมือซ้ำได้โดยตรงจากประวัติ
  * **＋ เพิ่มกลับเข้าคิว:** ดึงประวัติผู้ป่วยกลับเข้าคิวพิมพ์ใหม่ได้ทันที
  * **📊 ส่งออกข้อมูล CSV:** ส่งออกรายงานประวัติการพิมพ์เป็นไฟล์ Excel/CSV ได้ตามต้องการ

#### 1.3 ระบบคิวพิมพ์หลายชื่อพร้อมกัน (Batch Queue Printing)
* **ยิงบาร์โค้ดต่อเนื่องได้หลายคน:** สแกน HN / AN ของผู้ป่วยคนที่ 1, 2, 3... เข้าสู่คิวพิมพ์ได้อย่างรวดเร็ว
* **ระบบป้องกันข้อมูลซ้ำ (Duplicate Prevention):** หากสแกนผู้ป่วยที่มีอยู่ในคิวแล้ว โปรแกรมจะไฮไลต์แถวเดิมพร้อมกระพริบเตือนสีเหลือง โดยไม่สร้างรายการซ้ำ
* **พิมพ์ทั้งหมดในคิว (ปุ่มลัด F9):** สั่งพิมพ์สายรัดข้อมือของทุกคนที่เลือกพร้อมกันทีเดียว

#### 1.4 โหมดแถบข้างปรับพอดีหน้าจออัตโนมัติ (Auto-fit Sidebar Mode)
* กดปุ่ม **`📌 แถบข้าง`** หน้าต่างจะปรับขนาดเป็นแถบแนวตั้งแนบขอบขวาของจอ (กว้าง ~400px) และเปิดโหมด Always on Top อัตโนมัติ สามารถใช้งานร่วมกับหน้าต่างโปรแกรมอื่นได้โดยไม่บังพื้นที่ทำงาน
* ปรับเลย์เอาต์ไม่ให้ตกขอบ และสามารถกด **`⤢ ขยายเต็ม`** เพื่อกลับสู่หน้าจอปกติได้ทุกเมื่อ

#### 1.5 ล็อกอินค้างไว้ตลอด (Persistent Auto-Login)
* จดจำชื่อผู้ใช้งานและรหัสผ่านด้วยการเข้ารหัสความปลอดภัยระดับ Windows DPAPI
* เปิดโปรแกรมครั้งต่อไปเข้าสู่ระบบอัตโนมัติทันที พร้อมระบบ Heartbeat เชื่อมต่อค้างไว้ 24 ชม.

### 2. ปุ่มลัดคีย์บอร์ด (Keyboard Shortcuts)
| ปุ่มลัด | หน้าที่การทำงาน |
|:---:|:---|
| **Enter** | ค้นหาและเพิ่มผู้ป่วยเข้าคิวพิมพ์ |
| **Esc** | ล้างข้อมูลในช่องค้นหาและรีเซ็ตข้อมูลผู้ป่วย |
| **F9** | สั่งพิมพ์ทั้งหมดในคิว (หรือพิมพ์คนปัจจุบันหากไม่มีคิว) |
| **F4** | เปิดหน้าต่างประวัติการพิมพ์ย้อนหลัง / ค้นหาประวัติ / พิมพ์ซ้ำ |

### 3. การ Build & พัฒนาโปรแกรม
โปรแกรมคอมไพล์โดยตรงผ่าน C# Compiler (.NET Framework 4.0 x86) โดยไม่ต้องพึ่งพา Visual Studio ขนาดใหญ่

#### คำสั่งคอมไพล์ผ่าน `build.bat`:
```cmd
build.bat
```

หรือคอมไพล์ผ่านคำสั่ง csc:
```cmd
C:\Windows\Microsoft.NET\Framework\v4.0.30319\csc.exe /nologo /target:winexe /platform:x86 /out:bin\TUH_WristbandPrinter.exe /r:bin\AbsTools.Srv.dll,bin\DataWindow.dll,bin\AbsTools.CSUI.dll,bin\AbsTools.SrvCliNmSpace.dll,bin\zxing.dll,System.dll,System.Windows.Forms.dll,System.Drawing.dll,System.Security.dll,System.Runtime.Remoting.dll,System.Web.Extensions.dll /win32icon:app_icon.ico *.cs
```

### 4. โครงสร้างไฟล์ในโปรเจกต์
* `Program.cs` - จุดเริ่มต้นโปรแกรมและการตรวจสอบการล็อกอินอัตโนมัติ
* `MainForm.cs` - หน้าจอหลัก ระบบค้นหา HN/AN, ระบบคิวพิมพ์, แถบข้าง, การสั่งพิมพ์
* `HistoryForm.cs` - หน้าต่างค้นหาและดูประวัติการพิมพ์ย้อนหลัง พร้อมฟังก์ชัน Reprint และ Export CSV
* `PrintHistoryService.cs` - เซอร์วิสจัดเก็บประวัติการพิมพ์ลงไฟล์ JSON แบบปลอดภัย
* `LoginForm.cs` - หน้าจอเข้าสู่ระบบ ePHIS และการจำรหัสผ่าน
* `PreviewForm.cs` - หน้าต่างแสดงตัวอย่างสายรัดข้อมือจำลองเสมือนจริง
* `EphisService.cs` - เซอร์วิสเชื่อมต่อกับ ePHIS และ PowerBuilder DataWindow
* `Models.cs` - โครงสร้างข้อมูล (PatientAdmission, QueueItem, StaffUser ฯลฯ)
* `AppConfig.cs` - ระบบอ่านและบันทึกการตั้งค่าเครื่องพิมพ์ (`printer_config.ini`)
* `build.bat` - สคริปต์คอมไพล์โปรแกรมแบบคลิกเดียว
